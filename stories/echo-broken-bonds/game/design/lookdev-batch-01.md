# Proposed Look-Development Batch 01 — Awaiting Approval

This batch exists only to answer: **Does the proposed game look exciting, coherent, original, and worth continuing?** It does not authorize the rest of production.

## Provider and cost

- Provider: Higgsfield.
- Model: GPT Image 2, high quality, 2K.
- Requests: six images at 7 credits each.
- Maximum authorized spend if approved exactly as written: **42 Higgsfield credits**.
- Price is rechecked immediately before submission; any increase voids this approval and stops the batch.
- Automatic retries/rerenders: **none**. A failed image is reported before any additional spend.
- Audio/voice/video: none.
- Exact request bodies: `lookdev-batch-01-requests.json`. It freezes `job_type=gpt_image_2`, `quality=high`, `resolution=2k`, one returned image per request, supported aspect ratios, six full prompt hashes, and every permitted generated-reference dependency. The provider schema exposes no alpha/background flag; raw sheets use a prompted matte extraction background and make no claim of native transparency.

Each downstream request may use only the earlier outputs named in its `reference_asset_ids`; every resolved job/upload ID and raw hash is recorded. A hard-contract failure stops before any dependent request. Batch 01's **zero-retry rule overrides every broader retry ceiling in `asset-contracts.csv`**. No independent title art, final scene, animation, audio, voice, variant, rerender, or upscale is requested.

Before request 1, the reference-evidence packet required by `reference-lock.md` must exist and be hashed. The current governing Higgsfield terms/effective date, Ultra account plan, model schema, exact quote, and ownership/commercial-use/data-use conclusion must also be archived. A changed price, model, plan, or ambiguous rights conclusion voids approval.
