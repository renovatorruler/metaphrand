# Frosya and Vasya production instructions

For any Episode 1, Scene 1 production task, read these files completely before planning, prompting, generating, or editing assets:

1. `ep1prod/scene1/CURRENT.md`
2. `ep1prod/scene1/scene1.production.v1.json`

Those two files are the current operational authority for Scene 1. The spec script remains the story authority, but older shooting drafts, visual batches, and proposals are not production authority unless `CURRENT.md` explicitly promotes them.

Rules:

- Do not generate from chat memory alone.
- Do not silently reopen a closed decision.
- When the user changes or approves a production decision, update both current-state files in the same turn.
- Every generation must use the references declared for its shot in the manifest.
- Stop before generation when a shot has an unresolved blocking asset or contradictory state.
- Preserve rejected and superseded assets, but never treat them as current merely because they remain on disk.

Before discussing, reviewing, or editing the Episode 2 screenplay, read these files completely and in this order:

1. `2026-08-18_EP2_SCRIPT_HANDOFF.md`
2. `2026-08-11_EP2_samyi-krutoi-nomer_SPEC_numbered_bilingual.md`
3. `2026-08-11_EP2_APPROVED_DECISIONS.md`
4. `2026-08-12_EP2_FEEDBACK_REVISION_OPTIONS.md`
5. `2026-08-12_SERIES_MYSTERY_FOUNDATION_PROPOSAL.md`

Episode 2 authority rules:

- The numbered bilingual spec is the current screenplay text.
- The approved-decisions file records decisions accepted before that draft.
- The feedback file contains review notes and possible revisions. An item marked open is not canon and must not be applied without the author's approval.
- The mystery-foundation file contains proposals, not settled series canon.
- The handoff explains the current state, unresolved choices, and the exact next author decisions needed before rewriting.
- Do not infer a resolution from a recommended option, an existing draft choice, or an earlier brainstorm.
- Do not renumber the screenplay unnecessarily. When changes are approved, report the exact block IDs changed.
- Do not turn the literary spec into a shooting script until the story revision is approved.
