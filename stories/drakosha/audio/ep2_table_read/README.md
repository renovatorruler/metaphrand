# Episode 2 table-read artifacts

This directory contains the reproducible records for the English Episode 2 table reads.

- `EP2_FULL_CAST_TABLE_READ.manifest.json` and `ep2_table_read_plan.json` describe the first English render.
- `EP2_FULL_CAST_TABLE_READ_V2.manifest.json` and `ep2_table_read_V2_plan.json` describe the corrected English render with the US narrator Bella and the established character voices.
- `EP2_FULL_CAST_TABLE_READ_V2_WITH_SFX.manifest.json` and `ep2_sfx_plan.json` describe the SFX mix.
- `EP2_SFX_WORKFLOW.md` and `PSE_PULL_LIST.md` document the sound-effects workflow and licensed source pulls.
- `cache_v2/*.timings.json` preserves timing metadata for the paid V2 render.

The rendered MP3 files and cached audio chunks are intentionally ignored by Git under the repository's media policy. They remain local production artifacts. A local file is not proof of a working delivery link; the last externally supplied link for the English V2-with-SFX render did not open for the author.

Before any future table read, ask the author whether the requested language is Russian or English. English narration must use a native US English voice. Anna Zub is not approved for English narration because the accent was unsuitable; do not infer her nationality or multilingual ability from her name.
