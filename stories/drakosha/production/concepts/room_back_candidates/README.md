# SET-HOME-ROOM-01 — back-of-the-fireplace concepts

The family lives INSIDE the bricked-up fireplace. The hall is the fireplace's own cavity, and the giant sandstone boulder-blocks are its masonry seen at their size. There is no fireplace standing in their room — the room is the fireplace.

So the two ends of the hall are named for the fireplace, which cannot move, and never for the furniture, which can:

- **FRONT** — the riveted iron plate sealing the hearth mouth against the human room, with the small cleanout hatch set into it. Bound in the registry as `@ROOM_FRONT`, `@ROOM_FRONT_LOW`, `@ROOM_FRONT_HATCH` (author plates `SET-HOME-ROOM-01_author_master_v4_hatch_cradle-clear`, `_author_low_angle`, `_author_hatch_angle`).
- **BACK** — the brick rear of the fireplace. Bound as `@ROOM_BACK` (author plate `SET-HOME-ROOM-02_author_far_wall_v2`).

These files were previously called "reverse" views. That word is banned in this project: the reverse of the front is the back and the reverse of the back is the front, so no statement written with it can be checked. `Drakosha_SeedanceBatch.res` carries the same rule in a comment on `propToken`.
