# «Фрося и Вася» — Object and Scale Registry v1

**Purpose:** the shared dimensional reference for scene direction, layout, storyboards, animation, prop continuity, and later shooting scripts.

**Status:** Frosya's height, her permanent safety pin, and the matchbox-bed concept are author-locked. Other exact measurements below are working production defaults until a character lineup and set cutaway are approved.

> [!CAUTION]
> This Markdown registry is a design reference, not executable proof. Episode 1 shooting release is governed by the [machine-readable physical registry and preflight](./production/physical/README.md). `WORKING` and `CONSTRAINT` values cannot certify an action. The old chest-high drawer heave is rejected; the approved hook-and-shoelace replacement remains pending final asset measurement and machine certification.

This document records physical size in the human house. It does not describe apparent screen size or camera perspective.

---

## 1. Measurement law

### Master unit

`1 F = Frosya's standing height = 3.50 in = 8.89 cm`

Character height is measured barefoot from the floor to the top of the stable head/hair silhouette. Loose flyaway hairs, carried objects, and costume attachments do not add to height.

### Status labels

- **LOCKED:** explicitly approved canon; do not alter without the author.
- **WORKING:** production default; use it consistently until a model or set sheet replaces it.
- **CONSTRAINT:** the story requests this fit or clearance. It guides asset search but is **not evidence that the fit exists** and cannot pass the shooting-release gate.

### Precision levels

- **EXACT:** locked character heights and a small number of action-critical minimum/maximum clearances.
- **NOMINAL:** the intended visual size of furniture and ordinary props. Allow approximately 10% variation when selecting or designing the final asset.
- **FIT-DEPENDENT:** the relationship is more important than a catalog measurement: a character must fit, reach, lift, pass through, or be blocked convincingly.

Catalog dimensions may prove that a suitable human object exists, but they do not become false hundredth-of-an-inch canon. In particular, a matchbox bed is a family of repurposed objects, not one universal box that every character must share.

### Object classes

- **G — giant/full-world-scale object:** normally an ordinary human-world object retaining its real size and function; it also covers Baba Yaga's full folklore-scale flight assets before pipe normalization.
- **D — domovoy-scale object:** made, miniaturized, or magically materialized at a useful scale for the family.
- **R — repurposed giant object:** a recognizable human-world object retaining its physical size but serving a different function for the family.
- **SET — fixed environment:** architecture or required clearance rather than a movable prop.

Do not change an object's class merely because it changes owners. A human thimble used as a cup remains **R**. A new cup produced by Frosya's pencil is **D**.

### Baba Yaga's pipe rule

The chimney does not apply one mathematical reduction ratio to every carried item. It normalizes Baba Yaga and her belongings to **useful domovoy scale** while they spin together. Otherwise a human birthday candle reduced by Baba's body ratio would become unreadably tiny. Once an item exits the pipe, its size is fixed.

## 10. Continuity rules for scene directions

1. Every shooting-script prop should be named by registry ID on first appearance in a scene.
2. Use absolute dimensions for interaction and `F` units for quick visual comparison.
3. Perspective may change apparent size; the underlying model dimensions may not drift.
4. A **G** object remains genuinely human-sized. Never shrink it merely to make blocking easier.
5. An **R** object must remain recognizable as its source object. Adaptations may add ties, cloth, or handholds but may not erase the original silhouette.
6. A **D** object receives one fixed useful size when built, miniaturized, or materialized. It does not resize as it travels between rooms.
7. Baba Yaga's pipe and Frosya's pencil can create different useful sizes for different nouns; neither licenses arbitrary shot-to-shot scale changes.
8. Specific-person transformations are exact copies. Generic Vasya forms use the approved activation envelope for that occurrence.
9. Every frame should contain one clear scale anchor, but no character should carry more than two or three found objects visibly at once.
10. If a new action fails a fit test, change the action, set, or selected source prop in the registry before storyboarding. Do not hide the mismatch with camera framing.

## 11. Known document conflicts resolved here

- Frosya's large safety pin is **permanent**, not an optional per-scene extra.
- Frosya and Vasya have separate child-sized **matchbox beds**, while Mama and Papa share a larger fireplace-matchbox bed. Dad is never squeezed into Frosya's box.
- The magical pencil is not the safety pin. It joins Frosya's silhouette only after Baba Yaga gives it to her.
- A standard matchbox around 2.2 inches long is too short for 3.5-inch Frosya. Her bed uses the long-match format specified above, with nominal rather than catalog-exact dimensions.

Older descriptive files should defer to this registry on these four points until they are reconciled in a dedicated canon-cleanup pass.
